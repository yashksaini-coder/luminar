## Visual language (from the references)

1. **Grid frame** (Axiom Zero): the page sits inside a 1 px `--hair` grid. Section blocks are cells of
   that grid; small `+` registration marks sit on every grid intersection at the page gutters. Content
   panels can carry a diagonal hatch background (`--hatch`) like Axiom's left hero cell.
2. **Mono slash nav**: centered links `/ SIMULATOR  / ATTACKS  / RECORDINGS  / GITHUB`, wordmark left,
   one boxed CTA right (`Open the simulator`). Island collapse ≤1024 as now.
3. **Pixel art as the hero visual** (Axiom pixel blob, Antimetal dot sphere): a large animated
   `PixelField` canvas — a slowly rotating dot-matrix sphere/mesh of the gossip network made of square
   pixels whose density follows a 3D shaded form, with a status chip on top `ALL PEERS GOSSIPING ▮▮▮▮`
   and a stats bar below (`PEERS 50_ · PRUNED IN 2 HEARTBEATS_ · DELIVERY 100%_` with blinking
   underscores), numbers from `web/lib/reel-stats.json`.
4. **Dither-header cards** (pink swirl cards): three tall cards, each with an animated dither pattern
   header (swirl / rays / concentric), a large title, a short paragraph, a full-width CTA bar. Use them for
   the three attacks: Sybil (rays converging), Eclipse (concentric rings closing on a centre), Partition
   (a field split by a gap). Flame tint only on the attacking part.
5. **Halftone statement panels** (Lighthouse HQ, Cotool): big serif statements over a halftone dot grid
   whose dot size varies with a slow-moving field (blue/cyan or flame tint), small mono attribution below.
6. **Problem framing** (fixpoint): centred two-line statement with one highlighted word, then three
   benefit columns with small pixel illustrations.
7. **Footer** (Framer portfolio): a large closing headline "Watch a network defend itself" with the CTA,
   a `[HOW IT WORKS]` mono list (SIMULATE · ATTACK · SCORE · REPLAY) beside a short paragraph, a
   `STAY CONNECTED` box with GitHub, a pixel-art piece (the network tree / sphere) on the right, and a
   bottom row `© 2026 LUMINAR` · `MIT LICENCE` · `DATA: ETHPANDAOPS (CC BY 4.0)`.

## Shared engine: `web/components/fx/` (foundation lane builds it; everyone uses it)

- `PixelField.tsx` + `pixel-field.ts`: one canvas component, props `{ preset, tint, cell, density,
  speed, className, aria-label }`. Presets: `sphere` (rotating shaded sphere of network nodes and
  edges), `swirl`, `rays`, `rings`, `split`, `halftone` (dot size from a moving noise field), `scatter`
  (Cotool-style dot cloud). Draw at cell resolution, threshold with the existing Bayer matrix from
  `web/components/dither/dither.ts` (or circular dots for `halftone`/`scatter`), crisp
  `image-rendering: pixelated`. Runs on requestAnimationFrame only while ≥ 10 % on screen
  (IntersectionObserver), DPR capped at 2, ≤ 2 ms per frame at 600×600; `prefers-reduced-motion` draws
  one still frame; server markup reserves the box (no CLS).
- `GridFrame.tsx`: the page grid lines and `+` marks (CSS only, aria-hidden).
- `Cursor.tsx` or a CSS class for the blinking `_` after stat values.
- Unit tests: presets render deterministic frames for a fixed t (pure functions in `pixel-field.ts`),
  reduced motion draws once, IO pauses.

## Rules

- Tokens only; square corners (`--r-0`) except the CTA chips if a reference look demands (owner's
  call: keep square). No new fonts. No gradients in backgrounds (the halftone field is dots, not a
  gradient).
- Every number from `web/lib/reel-stats.json`, the reel manifest or the engine constants.
- Accessibility: Radix gives keyboard + ARIA for accordion/tabs; canvases are `role="img"` with labels
  or `aria-hidden` when decorative; 44 px touch targets; contrast AA; reduced motion stills; no audio
  plays without a user gesture.
- Responsive 390 / 768 / 1024 / 1440 / 1920, no horizontal page scroll.
- Checks: `cd web && npx tsc --noEmit && npm run lint && npx vitest run && npm run build` green, lint 0
  warnings. Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
